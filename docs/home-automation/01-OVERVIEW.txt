KEY CONCEPTS
================================================================================

Discord Webhook:
├─ Native Discord feature for posting messages
├─ Direct HTTP POST from Frigate
├─ No bot required
├─ Embedded images + rich formatting
├─ Rate limit: 10 requests/second
└─ Cost: $0.00

Clawdbot Webhook:
├─ HTTP endpoint for external integrations
├─ Receives Frigate events
├─ Routes to AI for analysis
├─ Delivers results to Discord
├─ Rate limit: 100 requests/minute
└─ Cost: ~$0.018 per analyzed event

Webhook Token:
├─ Cryptographic secret for authentication
├─ Generated with: openssl rand -hex 32
├─ Stored securely (env var or chmod 600)
├─ Rotated quarterly
└─ Never committed to git

Snapshot Image:
├─ JPEG image from Frigate camera
├─ Embedded in Discord embed
├─ Must be publicly accessible (Tailscale Funnel or proxy)
├─ Typical size: 50-200 KB
└─ Accessible via HTTPS

FREQUENTLY ASKED QUESTIONS
================================================================================

Q: Do I need to use both paths?
A: No. Path 1 (Discord direct) works standalone for immediate notifications.
   Path 2 (Clawdbot) is optional for selective AI analysis.

Q: Can I test before going to production?
A: Yes! Create test Discord channels and run discord-webhook-test.sh before
   deploying with real channels.

Q: What if my Frigate is behind a firewall?
A: Use Tailscale Funnel to expose snapshots publicly (see webhook-setup-guide.md
   Step 4, Option A).

Q: How often do I need to rotate tokens?
A: Quarterly is recommended. Emergency rotation if compromised.
   See webhook-tokens.txt for complete procedures.

Q: Can I customize the Discord embed format?
A: Yes! See frigate-config-example.yml for complete payload structure.
   Customize colors, fields, and images as needed.

Q: What if I don't want images in embeds?
A: Remove the image field from payload. Discord will still post metadata
   without the snapshot.

Q: Is this secure?
A: Yes. Uses HTTPS for all communication, bearer tokens for auth,
   secure storage guidelines, and rotation procedures included.

Q: What's the cost?
A: Path 1: Free (Discord webhooks). Path 2: ~$0.018 per analyzed event.
   Hybrid approach saves 90% vs analyzing everything.

Q: How long does setup take?
A: Quick start: 5 minutes. Full production: 50 minutes.
   Includes planning, config, testing, and documentation.

Q: What if I hit rate limits?
A: Discord: 10 req/sec max (add delay between Frigate notifications).
   Clawdbot: 100 req/min (configurable). See troubleshooting section.
