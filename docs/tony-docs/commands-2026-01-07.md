# Clawdbot Quick Commands

**Created:** 2026-01-07

## Aliases (added to ~/.bashrc)

| Command | What it does |
|---------|--------------|
| `clawd-check` | Check token expiry & service status |
| `clawd-reauth` | Run configure to re-authenticate |
| `clawd-restart` | Restart the service after re-auth |
| `clawd-status` | Check service status |
| `clawd-logs` | Follow live logs |

## Quick Fix Workflow

When clawdbot stops working with OAuth errors:

```bash
clawd-check          # See what's wrong
clawd-reauth         # Re-authenticate (Local → Model/auth → Anthropic OAuth)
clawd-restart        # Restart service
```

## Full Command Definitions

```bash
# Check auth token status
alias clawd-check="/home/admin/clawdbot/scripts/check-auth.sh"

# Re-authenticate with Anthropic
alias clawd-reauth="npx clawdbot configure"

# Service management
alias clawd-status="systemctl --user status clawdbot"
alias clawd-restart="systemctl --user restart clawdbot"
alias clawd-logs="journalctl --user -u clawdbot -f"
```

## Re-authentication Steps (clawd-reauth)

1. Run `clawd-reauth`
2. Select **Local (this machine)**
3. Select **Model/auth**
4. Select **Anthropic OAuth (Claude Pro/Max)**
5. Open the URL shown in your browser
6. Sign in with your Anthropic Max account
7. Click Authorize
8. Copy the code shown (format: `code#state`)
9. Paste it back in terminal **immediately** (codes expire fast!)
10. Run `clawd-restart` to pick up new tokens
